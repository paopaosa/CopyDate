CopyDate 隐私政策

生效日期：2026-09-17

CopyDate 是一款在 Windows 系统托盘中复制当前日期的小工具。本应用免费提供，不包含广告、账号或应用内购买。

我们收集哪些数据

CopyDate 不收集个人信息，不访问网络，也不会向开发者或第三方发送遥测、分析或崩溃报告。

本地存储

应用只会在本机保存你的偏好设置（例如默认日期格式、自定义格式、界面语言、是否开机启动、是否显示复制提示）。这些数据存放在 Windows 为当前用户提供的本地应用数据目录中，不会上传。

剪贴板

仅在你点击托盘图标或菜单项时，把所选日期文本写入系统剪贴板。应用不会读取剪贴板中的其他内容。

联系

如对隐私有疑问，请通过微软商店产品页中的支持联系方式联系开发者。

CopyDate Privacy Policy

Effective date: 17 September 2026

CopyDate is a free Windows system-tray utility that copies the current date to the clipboard. It has no ads, accounts, or in-app purchases.

Data we collect

CopyDate does not collect personal information, does not access the network, and does not send telemetry, analytics, or crash reports.

Local storage

Preferences (default date format, custom formats, UI language, start with Windows, copy notification) are stored only in this PC’s local app data folder.

Clipboard

The app writes the selected date text to the clipboard only when you click the tray icon or a menu item. It does not read other clipboard contents.
